待定 · Visual 0.2

这是网页版第二个视觉版本，重点不是堆新功能，而是让整体更接近苹果原生软件的气质。

本版变化：
- App 名称暂时改为「待定」
- 首页改为照片优先的双列陈列，支持大图 / 双列 / 列表切换
- 「归档」改为「曾拥有」并移入首页状态切换
- 底部栏改为：物品 / 时间线 / 统计
- 设置移动到右上角
- 新增分类快捷筛选、排序方式
- 新增总时间线和基础统计页
- 详情页重新排序：照片 → 名称 → 品牌型号 → 状态/分类 → 我的评价 → 陪伴天数/日均成本/价格 → 其他信息 → 时间线
- 封面新增九宫格位置调整，先解决自动裁切时主体被切掉的问题
- 沿用上一版 IndexedDB 名称，所以替换 GitHub Pages 文件后，原来的本机数据会继续保留
- Service Worker 改为新版缓存策略，后续更新更容易刷新到最新版

GitHub Pages 更新：
把 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png 替换到仓库根目录即可。
